# План ЛР5

Джерело: усі 11 сторінок «Лабораторна робота 5.pdf», SRS v1.0,
BDD SCN-01..07, OpenAPI 1.0.0, API-GATE GO від 31.10.2026.

1. LAB5-01: незалежні HTTP-тести всіх 15 операцій, негативні та граничні
   сценарії; RED; технічна перевірка TEST-GATE до серверного коду.
2. LAB5-02: стандартний Python WSGI, окремі service/repository/audit;
   локальне JSON-збереження, структуровані журнали; GREEN.
3. LAB5-03: рефакторинг без зміни контракту; повторні тести та git-знімок.
4. LAB5-04: після стабільної бази оформити одну зміну: перейменування
   колекції зі збереженням її зв'язків; адендум, тікет, OpenAPI, RED, GREEN.
5. LAB5-05: рефакторинг розширення, регресія, перевірка схем,
   вимірювання покриття і пошуку на 1000 записах, аналіз журналів.
6. LAB5-06: RTM, протокол, відповіді на контрольні питання, автоматичний
   запуск і перевірка. Людська валідація залишається окремою дією студента.

Без Docker, Node, зовнішньої БД, хмарних сервісів. Сервер працює лише на
127.0.0.1. Вхідний контракт не змінюється до адендуму.
Існуючі моделі й старі тести передували цій роботі: не представляємо їх як
новий TDD. Нові тести походять від SRS/контракту, але написані тим самим
агентом: причинна послідовність не означає незалежного людського аудиту.
Усі Gate-записи агента є технічними рекомендаціями, не підписом людини.
