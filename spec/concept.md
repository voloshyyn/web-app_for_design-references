# Концепція системи: Організація та каталогізація дизайн-референсів

## 1. Загальний задум
Інформаційна система призначена для збереження, систематизації та оперативного пошуку візуальних матеріалів (дизайн-референсів, мокапів, палітр, типографічних зразків, UI-компонентів та веб-посилань).
Система орієнтована на дизайнерів, арт-директорів та продуктових команд, допомагаючи швидко знаходити потрібні приклади під час роботи над проєктами.

## 2. Ключові сутності предметної області
- **Референс (Reference):** Основний об'єкт (зображення, посилання, заголовок, опис, дата додавання).
- **Колекція (Collection):** Тематична дошка або група референсів для конкретного проєкту/напряму.
- **Категорія (Category):** Загальна класифікація за типом (UI/UX, Брендінг, 3D, Ілюстрація, Анімація).
- **Тег (Tag):** Гнучка мітка для швидкої перехресної фільтрації (наприклад: #minimalism, #dark-mode, #onboarding).
- **Нотатка (Note):** Текстовий коментар або інсайт дизайнера до референсу.

## 3. Базові функціональні вимоги (Draft для Лабораторної №2)
- FR-1: Додавання референсу за прямим посиланням або завантаженням зображення.
- FR-2: Прив'язка референсу до однієї категорії та кількох колекцій.
- FR-3: Швидкий повнотекстовий пошук за назвою, нотатками та тегами.
- FR-4: Миттєва фільтрація за комбінацією тегів без перевантаження сторінки.
