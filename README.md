# Каталог дизайн-референсів — ЛР5

Локальний REST API на Python 3.10+, без серверних залежностей.
У PowerShell з каталогу проєкту:

```powershell
.\lab5.ps1 test    # встановить тестові залежності за потреби та виконає всі перевірки
.\lab5.ps1 demo    # завершена HTTP-демонстрація з тимчасовими даними
.\lab5.ps1 serve   # сервер на http://127.0.0.1:8000/api/v1
.\lab5.ps1 report  # відтворити PDF-протокол із поточних результатів
.\lab5.ps1 validate # делегована агенту валідація через HTTP
.\lab5.ps1 audit    # контрольовані відмови + тести + валідація
```

Якщо локальна політика PowerShell блокує скрипт:
`powershell -NoProfile -ExecutionPolicy Bypass -File .\lab5.ps1 test`.
Це діє лише для цього процесу. Для іншого порту: ` .\lab5.ps1 serve -Port 8001`.
Сервер зупиняється Ctrl+C; автоматичний demo завершує свій сервер самостійно.

Портативний запуск: `python -m src.api`; тести після
`python -m pip install -r requirements-dev.txt`: `python scripts/check_lab5.py`.
Інтернет потрібен тільки для першого встановлення тестових/PDF-залежностей.

## Файли та дані

- `spec/openapi.json` / `.yaml`: актуальний контракт 1.1.0, 16 операцій.
- `spec/openapi-baseline.json`: незмінна база 1.0.0, 15 операцій.
- `spec/addendum-001-collection-rename.md`: REQ-F-009, перейменування колекції.
- `data/catalog.json`: робочий стан; кожна успішна зміна зберігається атомарно.
- `logs/runtime/api.jsonl`: усі HTTP-дії, статус, operationId, request_id, час;
  startup/shutdown та помилки. Тіла запитів і нотатки не журналюються.
- `logs/lab5-*`: RED/GREEN, тести, покриття, вимірювання, Gate.
- `output/pdf/lab5-report.pdf`: протокол для завантаження у форму.
- `docs/lab5-form-answers.md`: відповіді на контрольні питання.
- `docs/lab5-human-validation.md`: межі делегованої перевірки агентом.

Для експорту/резервної копії зупиніть сервер і скопіюйте `data/catalog.json`.
Для імпорту власної сумісної копії: зупиніть сервер, збережіть поточний файл
окремо, замініть його копією та запустіть сервер. Пошкоджений JSON не
перезаписується порожнім каталогом: запуск завершується помилкою.
Одночасно працює один процес сервера з одним файлом даних.

## Архітектура та межі

`api.py` (HTTP/контракт) -> `service.py` (операції/транзакції) ->
`models.py` (наявна доменна модель) + `repository.py` (JSON).
`audit.py` відповідає за структуровані журнали. JSON екранує HTML-символи;
клієнт має виводити текст через textContent, а не innerHTML.

Це навчальний локальний API, не публічний багатокористувацький сервер.
Вебінтерфейс та його UX-критерій «до 3 кліків» не реалізовані цією серверною
лабораторною. Не заявляється валідація людиною або 100% покриття всіх
можливих помилок. Технічний Gate: GO після делегованої користувачем перевірки агентом.
Буквальна людська валідація з PDF і історична повнота поетапного TDD
бази не заявляються. Див. `logs/lab5-final-gate.md`.
