# Профіль кодингового агента проєкту

- **Ім'я інструменту:** Antigravity AI Coding Assistant (базова модель Gemini 3.8 Flash)
- **Клас інструменту:** Автономний інтегрований агент парного програмування (Autonomous IDE Coding Agent)
- **Спосіб доступу до репозиторію:** 
  - Прямий доступ до локальної файлової системи робочого простору (Read / Write / Replace).
  - Інтегроване виконання термінальних інструкцій у середовищі Windows PowerShell.
  - Автоматичне відстеження та інспекція історії Git.
- **Операції у робочому середовищі:**
  - Аналіз структури проєкту та перевірка цілісності SDD-артефактів.
  - Генерація початкових специфікацій, коду моделей, тестів та документації.
  - Внесення атомарних правок у вихідний код та супровідні документи.
  - Підготовка змін до комітів та участь у перевірці контрольних точок GIT-GATE.
