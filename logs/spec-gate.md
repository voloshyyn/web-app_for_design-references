## 2. Аналіз розв'язання відкритих питань ЛР1

1. **Глибина структуризації тегів:**  
   *Затверджене рішення:* Гібридне фасетне тегування (`namespace:value`) на базі пласкої множини рядків. Збережено швидкість $O(1)$ та простоту UX без необхідності заповнення обов'язкових таксономічних полів.
2. **Розподіл відповідальності Категорія / Колекція / Тег:**  
   *Затверджене рішення:* Категорія — взаємовиключна класифікація 1:1; Колекції — вільні призначені для користувача дошки N:M; Теги — дескриптори пошуку.
3. **Автоматичне тегування комп'ютерним зором:**  
   *Затверджене рішення:* Функція відхилена для версії v1.0 (Out-of-Scope) та зафіксована як кандидат для Адендуму на наступних ітераціях.
